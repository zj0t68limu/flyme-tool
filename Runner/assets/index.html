链接验证 / 还原器
把任何一个 Flyme 固件链接（官网带 auth_key 的临时链接、download.meizu.com 永久链接，或只含 时间戳/Hash 的片段）粘贴进来，自动解析机型、版本、构建时间，并还原成永久免签直链。
说明：数据来源、全量包与增量包、覆盖边界

一、各类标签分别代表什么

  • 官网稳定版 魅族官网固件页当前仍可下载的稳定版（当前/历史）。
  • 出厂系统 官网单独提供的“出厂系统”卡刷包，用于刷回出厂版本（如 21 的 10.5.5.1、21 PRO 的 10.5.1.0/10.5.5.1）。
  • 官网隐藏 官网已撤下、不再展示，但仍在官方 CDN 上的正式版（由官方固件汇总、固件库及社区帖子收录，本工具对直链进行连通性实测）。
  • 同版本多构建 同一版本号、不同构建时间戳的额外正式包（灰度/重新打包），体积与正式版不同，官方页面完全不展示。
  • 内测每日构建 CDN 路径为 cn_daily（每日构建）或 cn_beta（体验版）的内测 / 体验包；日构建版本号按日期编码（如 10.23.12.14 = 23 年 12 月 14 日的构建），未公开发布，仅内测渠道流出，数量庞大、默认折叠在“内测 / 体验版”分区。适合开发者 / 收藏，普通用户不建议刷。
  • 联名同平台 与 21 PRO 同硬件平台、由车厂换标推出的机型，独立于 Flyme 版本列表、单独成区展示：Polestar Phone（CDN 代号 PolestarPhone）、Lynk&Co Phone Pro（CDN 代号与 21 PRO 共用）。跨机型互刷前请务必确认机型与版本匹配。
  • 移动版 等系统版本（渠道）标签：同一机型的运营商定制版与海外版，包括 移动版 / 电信版 / 联通版 / 国际版 / 俄罗斯版 / 波兰版 / 印度版 / 阿里YunOS版 等。它们与公开版共享版本号、但文件不同，故在同一版本下并列展示并加渠道标签；可在「机型设置 → 机型系统版本」里勾选是否显示。默认的公开版为销售主力版本，不另加渠道标签。

二、关于“同版本多日期”

  • 魅族的版本号（如 10.5.0.1）并不唯一对应一个文件，正式发布前会有多次构建，CDN 路径里的 14位时间戳 和 8位Hash 才区分具体包。
  • 例：魅族21 的 10.5.0.1 有 2024-01-31 与 2024-03-29 两个构建；10.5.5.1 有同一天相差 36 分钟的两个构建。本工具已把所有发现的同版本多构建并列展示。
  • CDN 存储桶禁止目录列举，时间戳精确到秒且无法推算，官方也没有公开的历史构建查询接口。因此额外构建只能靠“多源聚合 + 逐条验证”收集，无法保证穷尽——未被任何第三方收录、也未在论坛流出的内测包，任何工具都查不到。

三、全量包 vs 增量包

  • 本工具列出的 update.zip 全部是数 GB 的全量卡刷包，可直接本地升级或降级（降级需按官方教程清除数据）。
  • 增量包（OTA 差分包，几十~几百 MB）只由手机“系统更新”App 针对“你当前的具体旧版本 → 新版本”临时下发，走独立接口、带设备校验，没有公开、可通用的独立直链，无法在此提供。这是官方机制决定的，不是工具遗漏。

四、直链为什么是“永久”的

  • 官网下载按钮给的是 firmware-res.flyme.com/...?auth_key=… 临时签名链接，会过期；把域名换成旧域名 download.meizu.com 并去掉 auth_key，即得到永久免签直链（本工具所有链接均为此形式；工具以 Range 请求实测连通性并读取真实体积，未通过的链接会标记为“CDN已失效”并禁用下载）。
  • 路径中的 8 位 Hash 等于该版本 MD5 的末 8 位，可用于核对文件完整性。
